# EmotePlayer

本目录提供 `emoteplayer.dll` 的兼容入口；E-mote 播放、状态更新与渲染等主体实现位于相邻的 [`motionplayer`](../motionplayer/) 目录。

本项目的 EmotePlayer 实现与兼容性工作大规模参考了 **AetherKiri** 的公开实现，包括 E-mote 数据解析、播放器生命周期、嵌套 motion、参数控制以及渲染合成等部分：

- [AetherKiri/AetherKiri](https://github.com/AetherKiri/AetherKiri)

感谢 AetherKiri 项目及其贡献者公开相关实现。具体授权与许可证要求以各仓库中的许可证文件为准。
